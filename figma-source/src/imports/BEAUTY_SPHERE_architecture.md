## 1. Обзор проекта

### 1.1. Назначение
Официальный дистрибьютор 15+ мировых брендов врачебной косметологии и профессиональной космецевтики. Сайт выполняет четыре ключевые функции:

1. **Витрина и продажа** — B2B интернет-магазин с верификацией покупателей (только для специалистов).
2. **Образовательная платформа** — семинары, курсы, сертификация.
3. **Дилерский канал** — работа с клиниками, салонами, частными косметологами по всей России.
4. **Экспертный бренд** — позиционирование Dr. Gulnara Rash и команды как лидеров индустрии.

### 1.2. Бизнес-цели
- Рост онлайн-заявок и повторных заказов от верифицированных специалистов.
- Снижение нагрузки на менеджеров через самообслуживание в личном кабинете.
- Продажа обучающих программ и формирование комьюнити.
- SEO-лидерство по запросам брендов (MonaLisa, Infini Lutronic, Dr. Nona, Arkana и т.д.).

### 1.3. УТП (USP)
Гарантия подлинности, прямые контракты с производителями, видимый клинический результат, обучение от ведущих экспертов, персональный менеджер, частые акции.

## 4. Структура ключевых страниц (блочная композиция)

### 4.1. Главная (/)
1. **Hero-блок** — логотип, УТП «Всё для работы косметологов», CTA «Войти / Зарегистрироваться как специалист», фоновое видео/изображение.
2. **Ключевые преимущества** (4 иконки): 15+ брендов, 100% оригинал, 150+ семинаров, доставка по РФ.
3. **Популярные бренды** — слайдер логотипов с переходом на страницу бренда.
4. **Категории каталога** — плиточная сетка (Филлеры / PLA / Космецевтика / Аппараты…).
5. **Бестселлеры / Хиты** — карусель из 8–12 товаров.
6. **Акции и спецпредложения** — 2–3 крупных баннера.
7. **Обучение** — ближайший семинар + кнопка «Все программы».
8. **5 причин выбрать нас** — блок из брифа заказчика.
9. **Экспертный блок** — Dr. Gulnara Rash, цитата, ссылка на Instagram.
10. **Отзывы клиентов** — карусель с фото и клиниками.
11. **Блог / Полезное** — 3 последние статьи.
12. **CTA + Контакты** — форма «Стать партнёром», карта, телефон.
13. **Footer** — каталог, обучение, документы, соцсети, подписка на рассылку.

### 4.2. Каталог (/catalog)
- Левый фильтр: бренд, категория, тип процедуры, показание (морщины, акне, объём), цена, в наличии, страна.
- Сортировка: популярность, цена, новинки, скидка.
- Сетка карточек (3–4 колонки десктоп, 2 планшет, 1 мобайл).
- Бейджи: «Хит», «Акция −20%», «Новинка», «Только для специалистов».
- Пагинация + «Показать ещё».
- SEO-текст внизу категории.

### 4.3. Карточка товара (/product/{slug})
- Галерея + видео применения.
- Название, бренд, артикул.
- Цена (видна только после верификации) / «Войдите для просмотра цены».
- Варианты (объём, комплектация).
- Кнопки «В корзину», «В избранное», «Быстрая заявка».
- Вкладки: Описание · Состав · Показания · Протокол применения · Сертификаты · Отзывы · Вопрос эксперту.
- Блок «С этим товаром покупают» + «Того же бренда».
- Блок «Семинар по этому препарату» (связь с /education).

### 4.4. Страница бренда (/brands/{slug})
- Hero: логотип, страна, официальный статус дилера.
- Описание бренда и философии.
- Линейки продукции (сегментация).
- Каталог товаров бренда.
- Ближайшие семинары по бренду.
- Сертификаты дистрибьюторства (скан).

### 4.5. Обучение (/education)
- Расписание (календарь / список).
- Типы программ: очные семинары (Махачкала), онлайн-курсы, выездные, мастер-классы.
- Фильтры по бренду, формату, дате, эксперту.
- Карточка курса: программа, цена, длительность, сертификат, даты, записаться.
- Форма регистрации → оплата → доступ в ЛК.

### 4.6. Личный кабинет (/account)
- Профиль (ФИО, специализация, клиника, документы).
- Статус верификации.
- История заказов + трекинг.
- Повторить заказ в 1 клик.
- Закрывающие документы (PDF).
- Бонусный баланс и история начислений.
- Мои курсы (видео-плеер, материалы, тесты, сертификат).
- Чат с персональным менеджером (виджет).

## 5. Пользовательские сценарии (User flows)

### 5.1. Новый специалист → первая покупка
Главная → Регистрация → Заполнение профиля + загрузка диплома → Ожидание верификации (email/SMS) → Активация → Просмотр каталога с ценами → Добавление в корзину → Чекаут (адрес, способ доставки СДЭК/Почта РФ, оплата картой/счёт) → Подтверждение → Email с накладной → Трекинг в ЛК.

### 5.2. Постоянный клиент → повторный заказ
Вход → ЛК → «Мои заказы» → «Повторить» → Корзина с теми же позициями → Применение бонусов/промокода → Оплата.

### 5.3. Запись на семинар
Главная → Обучение → Выбор курса → Регистрация → Оплата → Добавление в «Мои курсы» → Напоминание за 24 ч → Прохождение → Тест → Сертификат PDF.

### 5.4. Заявка от клиники (опт)
Главная → «Стать дилером» → Форма с ИНН → Менеджер связывается → Договор → Доступ к оптовым ценам.

### 6.2. Frontend
- **Next.js 14+ (App Router)** — SSR для SEO, ISR для каталога, CSR для ЛК.
- **TypeScript** обязательно.
- **UI-kit:** Tailwind CSS + shadcn/ui или Mantine.
- **Стейт:** Zustand / TanStack Query (для серверных данных).
- **Формы:** React Hook Form + Zod-валидация.
- **i18n:** next-intl (базово RU, задел под EN/AZ).
- **PWA:** офлайн-просмотр заказов и курсов, push-уведомления.
- **Анимации:** Framer Motion.

### 6.3. Backend
Два варианта — выбирается по команде/бюджету:

**Вариант А (готовая e-commerce платформа):**
- **1С-Битрикс** («Малый бизнес» / «Бизнес») — быстрый старт, интеграция с 1С из коробки, типовой B2B.
- **или MODX / OpenCart** — дешевле, но менее гибко.

**Вариант Б (кастомная разработка, рекомендуется):**
- **NestJS** (Node.js, TypeScript) — модульный монолит с чёткими границами модулей.
- **или Laravel 11 (PHP)** — если команда PHP-ориентирована.
- Архитектура — модульный монолит с возможностью выноса LMS и Auth в микросервисы по мере роста.

**База данных:**
- **PostgreSQL 16** — основная.
- **Redis** — кэш, сессии, корзины гостей.
- **Meilisearch / Elasticsearch** — поиск по каталогу и блогу.
- **S3-совместимое хранилище** (Yandex Object Storage / VK Cloud) — изображения, видео, дипломы, документы.

### 6.4. Инфраструктура и DevOps
- **Хостинг:** Yandex Cloud / VK Cloud / Selectel (российские юрисдикции для 152-ФЗ).
- **Оркестрация:** Docker + docker-compose на старте, Kubernetes на масштабе.
- **CI/CD:** GitLab CI / GitHub Actions → автодеплой на staging и prod.
- **CDN + WAF:** Cloudflare (или Yandex CDN для РФ).
- **Мониторинг:** Grafana + Prometheus, Sentry для ошибок, логи в Loki/ELK.
- **Бэкапы:** ежедневные, хранение 30 дней, тест восстановления раз в месяц.

## 9. Безопасность и соответствие законам

- **152-ФЗ** (о персональных данных): хранение на серверах в РФ, согласие при сборе ПДн, уведомление в Роскомнадзор.
- **54-ФЗ** (онлайн-касса): интеграция с ОФД через ЮKassa/АТОЛ-Онлайн.
- **38-ФЗ** (реклама): дисклеймеры о наличии противопоказаний, ограничение показа цен на рецептурные/медицинские изделия неспециалистам.
- Двухфакторная аутентификация (SMS/TOTP) для менеджеров и администраторов.
- Шифрование паролей (Argon2id), TLS 1.3 везде.
- Rate limiting на авторизацию и заявки, защита от парсинга каталога (CAPTCHA + лимиты).
- Резервное копирование + тест восстановления.
- Аудит действий в админке (`audit_log`).
- Регулярный security review (OWASP Top 10, SAST).

## 14. Риски и рекомендации

- **Риск:** показ цен на рецептурные изделия неспециалистам → юридические вопросы.
  **Решение:** жёсткая верификация, цены строго за логином, дисклеймеры.
- **Риск:** парсинг каталога конкурентами.
  **Решение:** rate limits, WAF, разные цены для разных сегментов, водяные знаки на фото.
- **Риск:** расхождение остатков сайта и склада.
  **Решение:** синхронизация с 1С не реже раза в 15 минут + резервирование при заказе.
- **Риск:** низкая конверсия из-за сложной верификации.
  **Решение:** двухшаговая регистрация (сначала доступ без цен, потом полная верификация); персональный менеджер звонит в течение часа.
- **Риск:** блокировка сайта из-за рекламных ограничений на медизделия.
  **Решение:** юридическая проверка всех текстов, корректные дисклеймеры, оформление по требованиям Роскомнадзора и ФАС.
