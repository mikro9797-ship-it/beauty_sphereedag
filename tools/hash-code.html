Как добавить новый код

  1. Введите код выше — он сразу превратится в SHA-256 хэш
  2. Нажмите «Скопировать хэш»
  3. Откройте файл js/data.js
  4. Найдите массив accessCodeHashes
  5. Вставьте новый хэш строкой (в кавычках, через запятую)
  6. Сохраните файл и закоммитьте на GitHub — код заработает на сайте

Пример вставки в data.js

accessCodeHashes: [ "уже_существующий_хэш...", "новый_хэш_который_вы_только_что_сгенерировали" ←← сюда ]
