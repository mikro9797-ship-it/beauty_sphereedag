## Как запустить локально

Открыть `index.html` двойным кликом.

## Деплой на GitHub Pages

1. Создать репозиторий на github.com (например, `beauty-sphere`)
2. Запушить эту папку (см. инструкцию ниже)
3. **Settings → Pages → Source: Deploy from a branch → main → /(root) → Save**
4. Через 1–2 минуты сайт будет на `https://<your-login>.github.io/<repo-name>/`

## Альтернатива — Netlify Drop

Перетащить папку с этими файлами на [netlify.com/drop](https://app.netlify.com/drop). Через 30 секунд получите рабочую публичную ссылку. Для своего домена — добавить его в настройках.

## Как добавить новый код доступа для клиента

1. Открыть `tools/hash-code.html` в браузере
2. Ввести любой код, который вы хотите выдать клиенту (например, `VIP-АННА-2026`)
3. Скопировать сгенерированный SHA-256 хэш
4. Открыть `js/data.js`, найти массив `accessCodeHashes`
5. Добавить новый хэш строкой
6. Закоммитить и запушить — код сразу заработает на сайте
7. Отправить клиенту в WhatsApp оригинальный код (не хэш)

## Как обновить каталог

Все товары хранятся в `js/data.js` в массиве `PRODUCTS`. Каждый объект имеет поля:
```js
{ id, name, brand, category, price, volume, image, description, inStock }
```
- `price: 0` ⇒ показывается «По запросу»
- `inStock: false` ⇒ бейдж «Под заказ» и серая карточка
- `image` — путь к фото (`images/p001.jpg` для локальных или внешний URL)

Для крупных обновлений каталога есть скрипт `build_data.py` (в этой ветке отсутствует — лежит у разработчика).
